✔ Correct Answer

Use Floyd's Cycle Detection (Tortoise and Hare algorithm):

def hasCycle(head):
    slow = head
    fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False
🔊 Explanation

We use two pointers, one moving slow and the other fast. If there is a cycle, they will eventually meet inside the loop in linear time with constant auxiliary memory.

Dynamic Programming

NeetCode Pattern
Playing explanation... 0:12 / 3:45

Dynamic Programming (DP) is a problem solving technique where we break a large problem into smaller subproblems, solve each subproblem once, store their results, and combine them to get the final answer. It is mainly used when the problem has overlapping subproblems and optimal substructure.

💡 Intuitive Analogy

Think of DP like a recipe book: you solve small sub-recipes, save them in memory, and combine them for the full feast. Each subproblem is solved once and reused hundreds of times.

Time Complexity O(n) to O(n·W) Subproblems × transition time
Space Complexity O(n) / O(1) Tabulation / State reduction
Mental Model Overlapping Subproblems Memoization vs Tabulation
